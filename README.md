# QuickNotes

## Description
QuickNotes is a  responsive note-taking web application built with html,css and JavaScript. It allows users to quickly jot down, organize, search and manage personal, work and study notes directly in the browser with persistent local storage.

## Features
- Add notes categorized as Personal, Work or Study.
- Input validation ensuring notes are non-empty and under 200 characters.
- Live search filtering to easily find specific notes.
- Dynamic note counter tracking total records.
- Persistent data storage using the browser's localStorage.
- Responsive design tailored for mobile and desktop screens.

## How to Run Locally
1. Clone or download this repository to your local machine.
2. Open the project folder in code editor (such as VS Code).
3. Open index.html directly in your browser or use an extension like Live Server to run it locally.
